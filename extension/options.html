Skill Pet

Open Skill Studio → (make skills, stickers and pets)

Your key is stored only in this browser profile (chrome.storage.local) and sent only to openrouter.ai (and the Figma token only to api.figma.com). MVP only: a real release would go through a backend.

Create one at openrouter.ai/keys. Any id from openrouter.ai/models, e.g. anthropic/claude-opus-5.5, anthropic/claude-haiku-4.5. Lets pets read a selected Figma frame crisply and post approved comments on it. Make one in Figma › Settings › Security › Personal access tokens (file read + comments write). Without it, pets work from a screenshot.

Shortcuts: Alt+Shift+P search skills, Alt+Shift+L lasso, Alt+Shift+S show/hide the squad, Alt+Shift+R rerun the last skill, Alt+1…9 use pet 1–9 on your pick, Alt+drag lasso anywhere, Alt+/ all shortcuts. Change them at chrome://extensions/shortcuts.
